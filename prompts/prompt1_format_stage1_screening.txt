# 【このファイルの使い方】
# 1. 下の「入力列定義」セクションで、Excelから読み込みたい列名を
#    「列名: [入力N]」の形式で1行ずつ記載する（Nは1から始まる連番）。
#    - この行は streamlit_app.py の自動列検出ロジックが読み取るため、
#      「列名: [入力N]」の書式・1行1定義を厳守すること。
#    - 各 [入力N] の最初の定義行だけが列名として採用され、
#      本文中で同じ [入力N] を再度参照しても定義は上書きされない。
# 2. [入力1]、[入力2]... のプレースホルダーは、実行時に対象Excel行の
#    実際のセル値へ自動的に置き換えられる。本文中で繰り返し参照してよい。
# 3. 出力は「厳格なJSON」のみとすること。説明文・前置き・```のような
#    コードフェンスを一切付けないこと（付けるとJSON解析に失敗し、
#    is_relevant=False・reason="JSON形式エラーにより棄却" として扱われる）。
# 4. 出力JSONのキーは以下の2つに固定すること（Stage1専用の必須スキーマ）。
#      - is_relevant : true または false（真偽値）
#      - reason      : 判定理由を記述した文字列
#    このJSONはコード側で固定列（1_Judgment / 1_Reason）に書き込まれる。
#    Stage2のような自由なキー名は使えない。
#
# 以下、この説明用コメント行（#で始まる行）は削除してから使用すること。

論文タイトル（英語）: [入力1]

# ------------------------------------------------------------
# 判定指示（ここに実際のスクリーニング条件を記載する）
# ------------------------------------------------------------

下記の論文情報を確認し、調査対象に「該当」するか「非該当」であるかを判定してください。

【対象論文】
- タイトル: [入力1]
- アブストラクト: [入力2]
- 本文: [入力3]

【判定基準】
- （該当と判断する条件を具体的に記載する）
- （非該当と判断する条件を具体的に記載する）
- （複数条件がある場合は、判定フローとして順序立てて記載することを推奨）

【判定ルール】
- 判定に使用してよい情報は [入力1]～[入力3] のみとする。
- [入力1]～[入力3] に記載されていない内容を、一般知識・外部情報・著者情報等から
  推測して補完してはならない。
- 各判断は、[入力1]～[入力3] の原文によって直接裏付けられている必要がある。

【出力ルール（最重要）】
- 出力は必ず次のJSON形式のみとする。前後に説明文・コードフェンスを付けないこと。
- キーは "is_relevant"（真偽値）と "reason"（文字列）の2つのみ。

該当の場合の出力例:
{"is_relevant": true, "reason": "該当と判断した理由をここに記載"}

非該当の場合の出力例:
{"is_relevant": false, "reason": "非該当と判断した理由をここに記載"}
