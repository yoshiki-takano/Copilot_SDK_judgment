// 【入力列の書き方】
// - Excelの値は、冒頭の【入力データ】にある「【入力N】列名: [入力N]」の行に差し込まれます。
// - 先頭の【入力N】は、本文の「入力N」がどのデータかをモデルに示すラベルです（列名の検出では無視されます）。
//   番号と項目の対応はこの行だけに書けばよく、本文で改めて説明する必要はありません。
// - N は 1 から連番で付けてください（欠番があっても画面でその番号の列選択が必要になります）。
// - 列名はExcelの見出しと同じ表記にすると、画面の列選択の初期値に自動で入ります。
// - 括弧付きの [入力N] は、ファイル内の出現箇所すべてが値に置き換わります。
//   本文で入力を指すときは括弧なしで「入力1」と書き、括弧付きは【入力データ】の行だけにしてください。
// - 【入力データ ここから】【入力データ ここまで】の行は、長い全文の境目をモデルに示すための区切りです。消さないでください。
// - Stage 1 と Stage 2 を続けて実行する場合、[入力N] には両方のプロンプトで同じ列が入ります。
//   Stage 1 と同じ番号には同じ列を割り当ててください（画面の初期値は Stage 1 側の列名が優先されます）。
//
// 【作業対象シート（任意）】
// - 下の「作業対象シート：」の行の先頭の // を外すと、画面のシート選択に自動で反映されます。
//   Stage 1 と Stage 2 の両方に書いた場合は Stage 1 側が優先されます。
//
// 【実行条件】
// - Stage 1 + Stage 2 を続けて実行する場合、Stage 2 は Stage 1 で「該当」となった行だけに実行されます。
// - Stage 2 のみを実行する場合は、全行に実行されます。
//
// 【出力】
// - 出力はJSONオブジェクト1つのみです。キー名は自由に決められます。
// - 各キーは、先頭に「2_」を付けたExcelの列見出しとして自動で追加されます（例："ベクター種類" → 2_ベクター種類）。
//   分かりやすい列見出しになる名前にしてください。
//   - 入れ子のオブジェクト {"a": {"b": 1}} は「2_a.b」列に展開されます。
//   - 文字列のリスト ["x", "y"] は「x; y」として1セルにまとめられます。
//   - オブジェクトを含むリストは、JSON文字列のまま1セルに入ります。
// - 一番外側を配列（[...]）にしないでください。複数行に書き込まれ、下の行のデータが上書きされます。
// - 毎回同じキー名で出力させてください。キー名が変わると、そのたびに新しい列が増えます。

抽出に使用する情報は、以下の【入力データ】に示す入力1～入力3のみとします。

// ↓ 「【入力N】列名: [入力N]」の形式で1行に1つ。Stage 1 と同じ番号には同じ列名を書き、【入力N】と [入力N] の番号をそろえてください
【入力データ ここから】

【入力1】論文タイトル（英語）: [入力1]

【入力2】アブストラクト（英語）: [入力2]

# 抽出項目

// ↓ 抽出したい項目を記載してください。項目名は出力JSONのキー名（＝Excelの列見出し）と一致させてください
- 項目1：（何を抽出するか。例：使用しているベクターの種類）
- 項目2：（何を抽出するか。例：対象ホスト細胞）
- 根拠原文：抽出に使用した原文全文（省略せずに記載）


# 抽出ルール

- 抽出に使用してよい情報は入力1～入力3のみとする。
- 入力1～入力3に記載されていない内容を、一般知識・外部情報等から推測して補完してはならない。
- 該当する情報が原文に存在しない場合は、空文字列 "" とすること。


# 出力形式（最重要）

出力は、下の出力例と同じキーを持つJSONオブジェクト1つのみとすること。

- キー名は出力例と完全に同じにし、キーの追加・削除・名称変更をしないこと。
- JSON以外の文字（前置き、説明文、```json などのコードフェンス、末尾のコメント）は一切出力しないこと。
- 値の中の改行は \n、ダブルクォーテーション（"）は \" とエスケープすること。

// ↓ キー名を【抽出項目】の項目名と一致させてください
出力例：
{"項目1": "抽出した値", "項目2": "抽出した値", "根拠原文": "抽出に使用した原文全文"}
