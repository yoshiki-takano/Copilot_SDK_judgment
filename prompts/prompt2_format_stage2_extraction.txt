# Stage 2（詳細抽出）プロンプト フォーマット
# ============================================================
#
# 【このファイルの使い方】
# 1. 下の「入力列定義」セクションで、Excelから読み込みたい列名を
#    「列名: [入力N]」の形式で1行ずつ記載する（Nは1から始まる連番）。
#    - Stage1と同じ入力列を使う場合は、Stage1プロンプトと同じ定義にすること。
#    - 各 [入力N] の最初の定義行だけが列名として採用され、
#      本文中で同じ [入力N] を再度参照しても定義は上書きされない。
# 2. [入力1]、[入力2]... のプレースホルダーは、実行時に対象Excel行の
#    実際のセル値へ自動的に置き換えられる。本文中で繰り返し参照してよい。
# 3. 出力は「厳格なJSON」のみとすること。説明文・前置き・```のような
#    コードフェンスを一切付けないこと。
# 4. Stage2はStage1と異なり、JSONのキー名は自由に決めてよい。
#    出力したJSONオブジェクトの各キーが、そのままExcelの新しい列見出しとして
#    自動的に追加される（rev_JSON_Fillout in Excel.py が処理する）。
#      - ネストしたオブジェクト {"a": {"b": 1}} は "a.b" という列名に展開される。
#      - 文字列のみのリスト ["x","y"] は "; " 区切りで1セルに結合される。
#      - オブジェクトを含むリストはJSON文字列としてそのまま1セルに書き込まれる。
#    そのため、キー名は分かりやすい列見出しになる日本語または英語にすること。
#
# 以下、この説明用コメント行（#で始まる行）は削除してから使用すること。
# ============================================================


# ------------------------------------------------------------
# 入力列定義（書式厳守：1行に "列名: [入力N]" を1つずつ）
# ------------------------------------------------------------

論文タイトル（英語）: [入力1]
アブストラクト（英語）: [入力2]
本文（全文）: [入力3]


# ------------------------------------------------------------
# 抽出指示（ここに実際の抽出項目を記載する）
# ------------------------------------------------------------

下記の論文情報から、必要な項目を抽出してください（この論文はStage1で「該当」と
判定済みであることが前提）。

【対象論文】
- タイトル: [入力1]
- アブストラクト: [入力2]
- 本文: [入力3]

【抽出項目】
- 項目1: （何を抽出するか説明する。例: 使用しているベクター種類）
- 項目2: （何を抽出するか説明する。例: 対象ホスト細胞）
- 項目3: （何を抽出するか説明する。例: 判定根拠となった原文）
- （必要な項目数だけ追加する）

【抽出ルール】
- 抽出に使用してよい情報は [入力1]～[入力3] のみとする。
- [入力1]～[入力3] に記載されていない内容を、一般知識・外部情報等から
  推測して補完してはならない。
- 該当する情報が原文に存在しない場合は、空文字列またはその旨を記載すること。

【出力ルール（最重要）】
- 出力は必ず次のようなJSONオブジェクト1つのみとする。前後に説明文・
  コードフェンスを付けないこと。
- キー名はそのままExcelの列見出しとして使われるため、列見出しとして
  適切な名称にすること。

出力例:
{
  "項目1": "抽出した値",
  "項目2": "抽出した値",
  "項目3": "抽出した値",
  "根拠原文": "判定に使用した原文全文"
}
